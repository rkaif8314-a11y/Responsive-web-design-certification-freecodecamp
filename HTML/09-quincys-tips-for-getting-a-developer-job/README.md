# Quincy's Tips for Getting a Developer Job

HTML exercise demonstrating semantic elements for quotations and citations.

## Concepts
- `<q>` for a short inline quotation.
- `<blockquote>` for longer quotations.
- `cite` attributes for source URLs.
- `<cite>` for the title of a cited work.
- Semantic `<main>` and `<section>` structure.
