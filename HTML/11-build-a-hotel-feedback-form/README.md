# Hotel Feedback Form\n\n## Series\n\n**Responsive Web Design — HTML Series #11**\n\nThis exercise builds a complete hotel feedback form using semantic HTML and common form controls.\n\n## What this exercise teaches\n\n- Semantic page structure with `header` and `main`\n- The `form` element\n- `fieldset` and `legend` for grouping related controls\n- `label` and the `for` attribute\n- Text, email, and number inputs\n- `required`, `placeholder`, `size`, `min`, and `max`\n- Radio buttons\n- Checkboxes\n- The `checked` attribute\n- Select menus and options\n- The `selected` attribute\n- `textarea`\n- Submit buttons\n- `POST` form submission\n\n---\n\n## Complete code\n\nThe complete exercise is stored in `index.html`.\n\nThe HTML file is intentionally commented so this folder can be used later as a revision reference.\n\n## Code walkthrough\n\n### 1. HTML document structure\n\n```html\n<!DOCTYPE html>\n<html lang="en">\n```\n\n- `<!DOCTYPE html>` tells the browser to use modern HTML.\n- `lang="en"` declares English as the document language.\n\nThe `head` contains metadata and the page title:\n\n```html\n<meta charset="UTF-8" />\n<title>Hotel Feedback Form</title>\n```\n\n### 2. Semantic page structure\n\n```html\n<header>\n  <h1>Hotel Feedback Form</h1>\n  <p>...</p>\n</header>\n\n<main>\n  ...\n</main>\n```\n\n- `header` contains introductory content.\n- `h1` is the main heading.\n- `main` contains the primary content of the page.\n\nSemantic elements make the document structure easier to understand and improve accessibility.\n\n### 3. The form\n\n```html\n<form method="POST" action="https://hotel-feedback.freecodecamp.org">\n```\n\n- `method="POST"` sends the submitted form data using POST.\n- `action="..."` specifies where the form data is sent.\n\nMemory:\n\n`form → collect data → submit data to action`\n\n### 4. Fieldset and legend\n\n```html\n<fieldset>\n  <legend>Personal Information</legend>\n  ...\n</fieldset>\n```\n\n- `fieldset` groups related form controls.\n- `legend` gives that group a descriptive title.\n\nThis form has groups for personal information, hotel visit history, reasons for choosing the hotel, and ratings.\n\n### 5. Labels and inputs\n\nExample:\n\n```html\n<label for="full-name">Name (required):</label>\n<input\n  type="text"\n  id="full-name"\n  name="name"\n  placeholder="e.g., John Doe"\n  required\n  size="20"\n/>\n```\n\nImportant attributes:\n\n- `type="text"` creates a normal text field.\n- `id="full-name"` uniquely identifies the input.\n- `for="full-name"` connects the label to the input.\n- `name="name"` identifies the submitted form field.\n- `placeholder` displays example text.\n- `required` prevents submission when the field is empty.\n- `size="20"` controls the visible width of the text input.\n\n### Label connection rule\n\n`label for="X"` ↔ `input id="X"`\n\nThe values should match.\n\n### 6. Email input\n\n```html\n<input type="email" name="email" id="email" required />\n```\n\n`type="email"` tells the browser that the field expects an email address and enables appropriate browser validation.\n\n### 7. Number input\n\n```html\n<input type="number" name="age" id="age" min="3" max="100" />\n```\n\n- `type="number"` creates a numeric input.\n- `min="3"` sets the minimum accepted value.\n- `max="100"` sets the maximum accepted value.\n\n## 8. Radio buttons\n\n```html\n<input id="yes-option" type="radio" name="hotel-stay" value="yes" />\n<label for="yes-option">Yes</label>\n\n<input id="no-option" type="radio" name="hotel-stay" value="no" />\n<label for="no-option">No</label>\n```\n\nBoth controls have the same `name="hotel-stay"`, so they form one radio group.\n\nThat means the user chooses **Yes OR No**, not both.\n\nMemory trick: **Radio = one choice from a group.**\n\n## 9. Checkboxes\n\n```html\n<input type="checkbox" id="ads" name="choice" value="ads" />\n<label for="ads">Social Media Ads</label>\n```\n\nCheckboxes allow multiple independent selections.\n\nFor example, a guest can select Social Media Ads, Location, and Price at the same time.\n\nMemory trick: **Checkbox = multiple choices allowed.**\n\n## 10. The checked attribute\n\n```html\n<input checked type="checkbox" id="reputation" name="choice" value="reputation" />\n```\n\nThe boolean attribute `checked` makes the checkbox selected when the page initially loads.\n\n## 11. Select and option\n\n```html\n<select name="service" id="service">\n  <option value="poor">Poor</option>\n  <option value="good">Good</option>\n  <option selected value="excellent">Excellent</option>\n</select>\n```\n\n- `select` creates the dropdown.\n- `option` creates each choice.\n- `value` is the value associated with the option.\n- `selected` makes an option selected by default.\n\nIn this exercise, **Excellent** is selected initially for service and food.\n\n## 12. Textarea\n\n```html\n<textarea cols="30" rows="10" name="comments" id="comments"></textarea>\n```\n\n`textarea` is used for longer text.\n\n- `cols` controls the approximate width.\n- `rows` controls the approximate height.\n- `name` identifies the submitted field.\n- `id` connects the textarea to its label.\n\n## 13. Submit button\n\n```html\n<button type="submit">Submit</button>\n```\n\n`type="submit"` tells the browser to submit the form.\n\n---\n\n# Most important revision points\n\n## Radio vs Checkbox\n\n| Control | Purpose | Selection |\n|---|---|---|\n| `radio` | Choose one option from a group | One |\n| `checkbox` | Choose independent options | Multiple |\n\n### Radio\n\n```html\n<input type="radio" name="hotel-stay" value="yes" />\n```\n\nSame `name` = same radio group.\n\n### Checkbox\n\n```html\n<input type="checkbox" name="choice" value="price" />\n```\n\nMultiple checkboxes can be selected.\n\n## Form attribute memory\n\n```text\naction  → where the data goes\nmethod  → how the data is sent\nname    → submitted field name\nid      → uniquely identifies an element\nfor     → connects a label to an id\nvalue   → value associated with a control\n```\n\n## Important boolean attributes\n\nThese can appear without a value:\n\n```html\nrequired\nchecked\nselected\n```\n\nExamples:\n\n```html\n<input required />\n<input checked />\n<option selected>Excellent</option>\n```\n\n## Common mistakes to avoid\n\n### 1. `radio`, not `ratio`\n\nWrong:\n\n```html\n<input type="ratio">\n```\n\nCorrect:\n\n```html\n<input type="radio">\n```\n\n### 2. Use the same name for Yes and No\n\nWrong:\n\n```html\n<input type="radio" name="yes" />\n<input type="radio" name="no" />\n```\n\nCorrect:\n\n```html\n<input type="radio" name="hotel-stay" value="yes" />\n<input type="radio" name="hotel-stay" value="no" />\n```\n\n### 3. Connect labels correctly\n\n```html\n<label for="email">Email</label>\n<input id="email" type="email" />\n```\n\nThe label's `for` value and the input's `id` value must match.\n\n### 4. Do not close input with `</input>`\n\n`input` is a void element.\n\nCorrect:\n\n```html\n<input type="text" />\n```\n\n## Quick revision map\n\n```text\nFORM\n│\n├── Personal Information\n│   ├── text input\n│   ├── email input\n│   └── number input\n│\n├── First hotel visit\n│   └── radio buttons\n│\n├── Why choose hotel?\n│   └── checkboxes\n│\n├── Ratings\n│   ├── select → service\n│   └── select → food\n│\n├── Other comments\n│   └── textarea\n│\n└── Submit\n    └── button\n```\n\n## One-line takeaway\n\n**A complete HTML form combines labels, inputs, radio buttons, checkboxes, dropdowns, textarea, fieldsets, and a submit button.**\n\n## Files\n\n- `index.html` — complete commented Hotel Feedback Form\n- `README.md` — detailed explanation and future revision notes
