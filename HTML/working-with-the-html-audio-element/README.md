# Working with the HTML Audio Element

A FreeCodeCamp Responsive Web Design HTML project demonstrating how to use the HTML `audio` element to add playable music to a webpage.

## Project

**Title:** freeCodeCamp Tunes

The page contains three music tracks:

- Can't Stay Down — Quincy Larson
- Cruising for a Musing — Quincy Larson
- Scratching the Surface — Quincy Larson

Each track includes an HTML audio player with:

- `controls` — displays the browser's audio controls.
- `loop` — repeats the audio when it reaches the end.
- `src` — specifies the audio file.

## HTML Concepts Practiced

- HTML document structure
- Headings with `h1` and `h2`
- Paragraphs with `p`
- The HTML `audio` element
- Audio `src` attribute
- Audio `controls` attribute
- Audio `loop` attribute
