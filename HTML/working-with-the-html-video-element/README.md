# Working with the HTML Video Element

A FreeCodeCamp Responsive Web Design HTML project demonstrating how to embed and configure video content using the HTML `video` element.

## Project

**Title:** Working with the HTML Video Element

The page contains a video player with:

- A width of 640 pixels
- Playback controls
- Looping enabled
- Muted playback
- A poster image shown before playback
- Multiple video source formats for browser compatibility

## HTML Concepts Practiced

- HTML document structure
- The `video` element
- The `source` element
- `controls` attribute
- `loop` attribute
- `muted` attribute
- `poster` attribute
- `width` attribute
- Video MIME types such as `video/mp4`, `video/webm`, `video/ogg`, and `video/quicktime`
