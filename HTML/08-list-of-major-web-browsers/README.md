# List of Major Web Browsers

HTML exercise demonstrating a description list using `<dl>`, `<dt>`, and `<dd>`.

## Concepts
- `<dl>` creates a description list.
- `<dt>` defines a term or name.
- `<dd>` provides the description for that term.

## Included Browsers
- Google Chrome
- Firefox
- Safari
- Brave
- Arc
