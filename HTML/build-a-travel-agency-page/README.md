# Build a Travel Agency Page

A FreeCodeCamp Responsive Web Design HTML project that demonstrates the use of semantic HTML elements to create a simple travel agency page focused on exploring Italy.

## Project

**Title:** Discover Italy

The page contains:

- A main heading introducing the travel agency.
- A description of Italy tours and experiences.
- A **Packages** section with links for Group Travels and Private Tours.
- A **Top Itineraries** section.
- Three travel itinerary figures with clickable images and captions.
- A meta description for the page.

## HTML Concepts Practiced

- HTML document structure
- `<!DOCTYPE html>`
- Semantic headings: `h1`, `h2`
- Paragraphs with `p`
- Unordered lists with `ul` and `li`
- Links with `a`
- Images with `img`
- Accessible image `alt` attributes
- `figure` and `figcaption`
- `meta` description
- `target="_blank"`
