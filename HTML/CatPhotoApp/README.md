# CatPhotoApp

A beginner-friendly HTML project from the **freeCodeCamp Responsive Web Design** curriculum.

## Project Overview

CatPhotoApp is a simple semantic HTML page that introduces basic HTML structure and common elements through a cat-themed example.

## Concepts Practiced

- HTML document structure
- `<!DOCTYPE html>`
- `html`, `head`, and `body`
- Headings with `h1`, `h2`, and `h3`
- Paragraphs with `p`
- Links with `a`
- Images with `img`
- Image `alt` attributes
- Unordered lists with `ul` and `li`
- Ordered lists with `ol` and `li`
- Semantic sections with `main` and `section`
- `figure` and `figcaption`
- Text emphasis with `em` and `strong`
- Footer content
- Opening links in a new tab with `target="_blank"`

## Main Features

### Cat Photos

The page contains links to cat photos and a clickable cat image that links to the cat photo gallery.

### Cat Lists

The page demonstrates both unordered and ordered lists:

- Things cats love
- Top 3 things cats hate

### Figures and Captions

The project uses `figure` and `figcaption` to associate images with descriptive captions.

## How to Run

Open `index.html` in any modern web browser.

## Learning Goal

This project focuses on building a clean HTML document using semantic elements and practicing links, images, lists, figures, and text formatting before moving on to CSS and responsive design.
