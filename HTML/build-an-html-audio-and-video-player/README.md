# Build an HTML Audio and Video Player

A FreeCodeCamp Responsive Web Design HTML project demonstrating how to embed both video and audio content in a webpage.

## Project

**Title:** HTML Audio and Video Lab

The page contains:

- A video section explaining the JavaScript `map()` method.
- A video player with controls and looping enabled.
- A "Sailing Away" audio player with controls and looping enabled.

## HTML Concepts Practiced

- HTML document structure
- Semantic headings
- `section` elements
- `video` element
- `audio` element
- `source` element
- `controls` attribute
- `loop` attribute
- `width` attribute
- Video and audio source URLs
- MIME types such as `video/mp4`
