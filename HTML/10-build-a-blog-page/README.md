# Build a Blog Page

FreeCodeCamp Responsive Web Design exercise — semantic HTML structure for a blog page.

## Concepts practiced
- Semantic elements: `header`, `main`, `section`, `article`, `footer`, and `address`
- Navigation links with fragment identifiers
- Images and `figure`/`figcaption`
- Contact links using `tel:` and `mailto:`
- Headings and paragraph structure
