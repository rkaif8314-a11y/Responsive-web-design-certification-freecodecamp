# Chocolate Chip Cookies

A beginner-friendly HTML recipe page created while following the **freeCodeCamp Responsive Web Design** curriculum.

## Project Overview

This project builds a simple recipe webpage for mini chocolate chip cookies. It uses semantic HTML to organize a title, description, recipe image, ingredients, and numbered cooking instructions.

## Concepts Practiced

- HTML document structure
- `<!DOCTYPE html>`
- `html`, `head`, and `body`
- Character encoding with `meta charset="UTF-8"`
- Page titles with `title`
- Headings with `h1` and `h2`
- Paragraphs with `p`
- Images with `img`
- Image `alt` text
- Unordered lists with `ul` and `li`
- Ordered lists with `ol` and `li`
- Semantic organization of recipe content

## Page Sections

### Recipe Introduction

The page starts with the recipe title and a short introduction describing the mini chocolate chip cookies.

### Recipe Image

An image from the freeCodeCamp curriculum is displayed using the `img` element with descriptive alternative text.

### Ingredients

An unordered list contains the required ingredients:

- All-purpose flour
- Baking soda
- Unsalted butter
- Granulated sugar
- Vanilla extract
- Mini chocolate chips

### Instructions

An ordered list contains the six recipe steps. An ordered list is used because the instructions need to be followed in sequence.

## How to Run

Open `index.html` in any modern web browser.

## Learning Goal

The main goal of this exercise is to practice structuring real-world content with HTML, especially headings, paragraphs, images, unordered lists, and ordered lists.
