# Build a Video Compilation Page

A semantic HTML page that organizes front-end web development topics into separate sections and embeds video content using `iframe`.

## Topics

- HTML
- CSS
- JavaScript

## Concepts Practiced

- Semantic HTML structure
- `main` and `section` elements
- Headings and paragraphs
- Embedding YouTube videos with `iframe`
- `iframe` titles and dimensions
- Accessible document structure
