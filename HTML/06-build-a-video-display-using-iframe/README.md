# Build a Video Display Using iframe

A simple HTML exercise demonstrating how to embed a YouTube video using an HTML `iframe`.

## Concepts Practiced

- HTML document structure
- The `iframe` element
- Embedding a YouTube video
- `allow` permissions
- `referrerpolicy`
- `allowfullscreen`
- Responsive viewport metadata

## File

- `index.html`

## Purpose

This exercise demonstrates how external video content can be displayed directly inside a webpage using an iframe.
