Introduction

Web development is the process of creating websites and web applications.

It combines technologies such as HTML, CSS, and JavaScript to create interactive experiences on the web.

The three basic technologies used on the frontend are:

  • HTML for structure
  • CSS for presentation
  • JavaScript for behavior
HTML Basics

HTML provides the structure and meaning of content on a webpage.

Elements such as headings, paragraphs, links, and images are written using HTML.

A basic HTML heading can be written using:

<h1>Hello World</h1>
CSS Basics

CSS is used to control the appearance and layout of HTML elements.

With CSS, you can change colors, spacing, fonts, borders, and positioning.

A CSS rule can be written like this:

p { color: green; }
JavaScript Basics

JavaScript adds behavior and interactivity to webpages.

It can respond to user actions and dynamically change webpage content.

You can display a message in the browser console using:

console.log("Hello World");
Responsive Design

Responsive design allows a webpage to work well on different screen sizes.

CSS media queries can change the layout depending on the device width.

A media query can begin like this:

@media (max-width: 768px) { }
