# Cafe Menu

A FreeCodeCamp Responsive Web Design CSS project that demonstrates how CSS can be used to style and lay out a cafe menu.

## Project

**Title:** Camper Cafe

The page contains:

- Coffee menu items and prices
- Dessert menu items and prices
- Cafe branding and establishment year
- Background imagery
- Footer with a website link and address

## CSS Concepts Practiced

- Background images
- Font styling
- Text alignment
- Width and max-width
- Automatic margins
- Padding
- Display properties
- Inline-block layout
- CSS classes
- Pseudo-classes such as `:hover`, `:visited`, and `:active`
- Styling horizontal rules
- Basic responsive layout structure
